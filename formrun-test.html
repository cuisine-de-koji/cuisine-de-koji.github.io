formrun のコード型フォーム検証ページ

このページは GitHub Pages 上で formrun のコード型フォームを試すための検証用ページです。 まずは action 属性の YOUR_FORMRUN_ACTION_URL を、 formrun 管理画面の「コード設置」に表示される URL に置き換えてください。

トップページへ戻る

使い方

  1. このファイル内の YOUR_FORMRUN_ACTION_URL を formrun の送信先 URL に置き換える
  2. formrun 管理画面の「フォームの埋め込み先を指定」に、このページの URL を登録する
  3. 保存後、このページからテスト送信して formrun 側に回答が入ることを確認する
